# OmniWeb OS - A Web-Based Mobile Operating System Simulator

Welcome to **OmniWeb OS**, a feature-rich, simulated mobile operating system that runs entirely in your web browser. This project, built with **Next.js** and **React**, showcases a beautiful and functional user interface designed with **Tailwind CSS** and **ShadCN UI** components. It also integrates cutting-edge AI features using **Genkit**.

## ✨ Key Features

*   **📱 Realistic OS Interface**: Experience a familiar mobile OS environment with a home screen, app icons, a dock, and a status bar.
*   **NAVIGATION**: On-screen navigation buttons (Back, Home, Recents) for an authentic mobile experience.
*   **🖼️ Stunning Visuals**: A sleek, modern design with light and dark themes.
*   **🤖 AI-Powered App Recommendations**: Discover new apps with suggestions generated by AI based on your usage patterns.
*   **📂 A Suite of Built-in Apps**:
    *   **Browser**: Surf the web within the OS.
    *   **Messages**: A mock-up of a messaging application.
    *   **Gallery**: Browse a collection of beautiful images.
    *   **Settings**: Toggle dark mode, manage settings, and access AI features.
    *   **Calculator**: A fully functional calculator for your basic math needs.
    *   **Notes**: A simple note-taking app that saves your thoughts to local storage.
    *   **Weather**: Get a 5-day forecast for a sample city.
    *   **Terminal**: A mock terminal with a few basic commands.
*   **🔗 Social Shortcuts**: Quick-launch apps that link directly to your social media profiles.
*   **🖥️ Fullscreen Apps**: Applications open in full-screen for an immersive experience.

## 🚀 Getting Started

To get this project running on your local machine, follow these simple steps.

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) and [npm](https://www.npmjs.com/) installed on your system.

### Installation

1.  **Clone the repository:**
    ```bash
    git clone <your-repository-url>
    ```
2.  **Navigate to the project directory:**
    ```bash
    cd <project-directory>
    ```
3.  **Install the dependencies:**
    ```bash
    npm install
    ```
4.  **Run the development server:**
    ```bash
    npm run dev
    ```

The application will now be running at `http://localhost:9002`.
