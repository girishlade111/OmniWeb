# **App Name**: OmniWeb

## Core Features:

- Home Screen: Display a customizable home screen with a dock and notification bar, mimicking a mobile OS UI.
- System Apps: Provide core system applications such as Contacts, Calendar, Browser, Messaging, File Explorer, and Settings.
- Notification System: Display and manage notifications from system apps.
- AI-Powered App Recommendations: Suggest apps to use based on usage patterns, using a tool that profiles the user's typical app selection choices.
- Settings App: Configure system settings such as Wi-Fi, Bluetooth, display, and privacy.
- Multitasking: Enable windowed multitasking to run multiple apps simultaneously.
- Universal Search: Implement a search bar to find apps, settings, and web content.

## Style Guidelines:

- Primary color: Deep Indigo (#6666B3) to convey a sense of modern technology.
- Background color: Very light gray (#F0F0F5).
- Accent color: Teal (#237A7A) for interactive elements and highlights.
- Body and headline font: 'Inter' (sans-serif) for a modern and clean interface.
- Use minimalistic and consistent icons for system apps and actions.
- Mobile-first design with intuitive drag-and-drop functionality for app customization.
- Smooth transitions and animations for opening, closing, and minimizing apps.
